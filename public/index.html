Integrasi Zabbix

Hubungkan User Manager ke Zabbix menggunakan API token yang disimpan terenkripsi di SQLite.

Gunakan API token khusus Zabbix dengan izin baca host dan host group. Token dikirim ke backend User Manager, tidak disimpan di browser, dan tidak pernah ditampilkan kembali. Pastikan URL API dapat diakses dari container User Manager.

Isolasi pelanggan

Blokir atau pulihkan akses melalui firewall address-list khusus aplikasi.

Konfigurasi firewall wajib: aplikasi menambahkan IP ke address-list USER_MANAGER_ISOLATED. Agar internet benar-benar terblokir, siapkan rule firewall filter yang menjatuhkan trafik pelanggan pada list tersebut. Aplikasi tidak mengubah atau menghapus rule firewall yang sudah ada.
